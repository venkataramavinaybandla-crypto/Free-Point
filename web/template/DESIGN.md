## Brand & Style

This design system delivers an ultra-high-precision developer cockpit engineered for orchestrating agentic tool-use, autonomous pull requests, and multi-modal sandbox execution. Blending brutalist runtime telemetry with high-luxury liquid-chrome surfaces, the aesthetic bridges raw low-level execution with high-status computing.

### Core Tenets
- **Programmatic Omnipotence:** Interfaces present dense, high-signal information density without cognitive clutter. Data flows like memory registers in a hyper-optimized kernel.
- **Chrome Specular Dynamics:** Deep metallic obsidian surfaces intersect with razor-sharp refractive highlights and a directional 135° prismatic chromatic spectrum (Teal, Electric Blue, Violet, Hot Pink, Red, Amber Orange).
- **Sub-Surface Luminosity:** Dark mode architecture illuminated by targeted, high-voltage cyan beacons and specular edges that mirror physical optical glass over raw milled obsidian.

## Colors

The system is calibrated around an ultra-deep obsidian baseline (`#080B10`) punctuated by a precise `#19C3C9` cyan keylight. Accent sequences draw from the rigid 135° diagonal luminous spectrum, deploying chromatic power sparingly to signify state mutations, safe sandbox executions, and programmatic status.

### Functional Palette
- **Canvas Base:** `#05070A` (Deepest void)
- **Surface Elevation 1 (Card/Bay):** `rgba(13, 18, 28, 0.72)`
- **Surface Elevation 2 (Popover/Modal):** `rgba(20, 27, 41, 0.88)`
- **Primary / Active Accent:** `#19C3C9` (Cyan laser highlight)
- **Spectral Sequence:**
  - Teal: `#19C3C9`
  - Electric Blue: `#2F6BFF`
  - Violet: `#8A4DFF`
  - Hot Pink: `#FF4FB6`
  - Red: `#FF4B55`
  - Amber Orange: `#FF9A3D`
- **Specular Stroke:** `linear-gradient(135deg, rgba(255, 255, 255, 0.24) 0%, rgba(255, 255, 255, 0.03) 50%, rgba(25, 195, 201, 0.35) 100%)`
- **Text Primary:** `#F8FAFC`
- **Text Secondary:** `#94A3B8`
- **Text Muted:** `#475569`

## Typography

The typographic engine uses Space Grotesk for architectural titles and section anchors, countered by the cold, tactical efficiency of JetBrains Mono for system payloads, code blocks, tabular runtime data, and core navigation labels.

### Usage Rules
- All numeric telemetry, execution statuses, and key-value inspect panes must be set in `JetBrains Mono`.
- Section headings leverage tighter negative tracking (`-0.02em` to `-0.03em`) to impart an intentional, aerospace-grade tension.
- Use uppercase for `label-sm` with widened letter-spacing (`0.08em`) to designate sandbox permission levels (e.g., `READ_ONLY`, `DEEP_EXEC`, `PULL_REQUEST`).

## Layout & Spacing

The viewport operates on a 12-column rigid grid bound to an 8px base rhythm. High-density sidebars and diagnostic drawers collapse along distinct spatial tracks to ensure zero-shift context switching during live runtime logs.

### Responsive Breakpoints
- **Mobile (< 768px):** Single-column stacked layouts, navigation docked as a fixed bottom capsule, 1rem margin, full-bleed diagnostic panes.
- **Tablet (768px - 1024px):** 8-column layout, persistent 240px utility sidebar, 1.5rem margin.
- **Desktop (1025px+):** 12-column grid, dual-rail layout (tree navigation on left, telemetry inspect on right), 2rem screen margin, max-width constrained to 1600px for data integrity.

## Elevation & Depth

Spatial separation relies on multi-layer composite specular borders, glass transmission, and high-frequency noise textures rather than heavy fuzzy drop shadows.

### Atmospheric Stack
- **Layer 0 (Substrate):** Solid deep carbon base with a 3% tactile stochastic grain and soft ambient 135° mesh gradient undercurrent.
- **Layer 1 (Panels & Shells):** Glass tiles featuring `backdrop-filter: blur(20px) saturate(180%)`, filled with `rgba(13, 18, 28, 0.65)`. Rimmed by a 1px border graded from `rgba(255, 255, 255, 0.12)` down to `rgba(25, 195, 201, 0.08)`.
- **Layer 2 (Floating Cockpit Modules):** Floating glass capsules and popovers leveraging `backdrop-filter: blur(28px)`, an inner hairline shadow (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`), and an external tinted ambient bleed: `0 16px 32px -8px rgba(0, 0, 0, 0.65), 0 0 16px rgba(25, 195, 201, 0.1)`.
- **Focus & Selection Beacons:** Direct UI focus triggers an intense 1px solid `#19C3C9` keyline paired with a `0 0 12px rgba(25, 195, 201, 0.35)` specular halo.

## Shapes

The geometric signature is defined by a controlled 0.25rem (`roundedness: 1`) baseline radius. Micro-components (tags, buttons, inputs) carry subtle 4px chamfers to deliver an authoritative industrial instrument aesthetic, while top-level structural bays scale to 8px (`rounded-lg`) and 12px (`rounded-xl`).

### Precision Detailing
- Zero spherical pill shapes, maintaining precise technical boundaries across all interactive modules.
- Split-buttons and tab arrays butt directly against each other with hairline 1px divider seams to simulate milled hardware modules.

## Components

### Buttons
- **Primary Action:** Solid `#19C3C9` background with deep `#080B10` bold text. On hover, shifts to liquid specular gradient with a sharp outer cyan bloom.
- **Secondary / Ghost:** Glass surface (`rgba(255, 255, 255, 0.04)`), 1px border (`rgba(255, 255, 255, 0.1)`), `#F8FAFC` monospace label. Hover introduces an inner edge highlight and border transition to `#19C3C9`.
- **Destructive:** Deep crimson tint (`rgba(255, 75, 85, 0.1)`), border in `rgba(255, 75, 85, 0.3)`, text in `#FF4B55`.

### Chips & Telemetry Tags
- Compact height (20px), set in `JetBrains Mono` at `label-sm`.
- Encased in `rgba(255, 255, 255, 0.03)` with a 1px peripheral border.
- Status pulses (e.g., active PR generation, sandbox hook active) use a 4px geometric diamond glyph illuminated in `#19C3C9` with CSS frame ping.

### Text Inputs & Command Lines
- Monospace typographic input field resting on an obsidian sink (`rgba(0, 0, 0, 0.4)`).
- Prefix iconography houses tool logos or root bash prompts (`$ ` or `api::`).
- Keyboard shortcut caps (`⌘K`) nested rightwards in micro-glass keys.

### Lists & Tree Views
- High-density rows (32px default height) with alternating hover states (`rgba(25, 195, 201, 0.04)`).
- Left-side indicator bar (2px width, `#19C3C9`) dynamically slides into position when a file, thread, or API trace is selected.

### Checkboxes & Radios
- Sharp 2px rounded square toggles.
- Checked state fills with `#19C3C9` hosting an obsidian vector mark, surrounded by a 2px offset specular border.

### Glass Cards & Tool Run Bays
- Modular panels hosting agent tools (Git pull requests, indexing engines, semantic inbox parsing).
- Rendered with 18px backdrop blur, subtle top-down metallic glare line, and an expandable header bay displaying real-time token throughput and memory allocations.
