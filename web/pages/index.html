HTTPS & SSRF guards

Model URLs must be HTTPS. Every connection resolves, checks each IP, pins the peer and follows no redirects.

Hashed API keys

Keys are shown once, stored as SHA-256 hashes with a public prefix. Passwords use Argon2id.

Approval-gated writes

Single-use, expiring approvals bound to hash(user, job, repo, base, head, title, body, diff).

Tenant isolation

Tenant ids in every storage key and per-user indexes. Only the RAE parser runs network-isolated.

One payload. Every tool behind a policy.

  -d '{

  }'
